### 1. Database Schema & Supabase Realtime Setup
Update and run migrations for the following Supabase tables with Row Level Security (RLS) enabled:

1. **`profiles`**
   - `id` (uuid, references `auth.users`, PK)
   - `username` (text, unique)
   - `avatar_url` (text)
   - `humor_preference` (`'general'` | `'tamil'`, default `'general'`)
   - `streak_count` (int, default 0)
   - `created_at`, `updated_at` (timestamptz)

2. **`friendships`**
   - `id` (uuid, PK)
   - `user_id` (uuid, references `profiles.id`)
   - `friend_id` (uuid, references `profiles.id`)
   - `status` (`'pending'` | `'accepted'` | `'rejected'`)
   - `created_at` (timestamptz)

3. **`direct_messages`**
   - `id` (uuid, PK)
   - `sender_id` (uuid, references `profiles.id`)
   - `receiver_id` (uuid, references `profiles.id`)
   - `content` (text)
   - `created_at` (timestamptz)

4. **`notifications`**
   - `id` (uuid, PK)
   - `user_id` (uuid, references `profiles.id`)
   - `type` (`'match_invite'` | `'platform_update'` | `'streak_milestone'` | `'friend_request'`)
   - `title` (text)
   - `payload` (jsonb) — contains `room_code`, `sender_name`, etc.
   - `is_read` (boolean, default false)
   - `created_at` (timestamptz)
